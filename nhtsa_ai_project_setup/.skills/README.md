# .skills

반복 가능한 작업을 스킬 단위로 표준화한 디렉터리입니다. 각 스킬은 `SKILL.md`로 구성되며, 언제 사용해야 하는지, 입력·절차·산출물·품질 게이트를 명시합니다.

## 스킬 목록

| Skill | 목적 |
|---|---|
| `nhtsa-data-contract` | CSV/SQLite 계약과 554건 코호트 재현 |
| `nhtsa-raw-time-history-ingestion` | raw signal/report/photo/video asset inventory |
| `channel-normalization` | 채널명·단위·축·센서 위치 표준화 |
| `side-loadcell-signal-processing` | 로드셀 force-time 처리와 load metrics |
| `vehicle-deceleration-delta-v` | 차체 감가속도, ΔV, 변위 산출 |
| `energy-estimation-member-mapping` | cell/zone/member 에너지 추정 |
| `manufacturer-model-benchmarking` | 제조사·모델별 특성 비교 |
| `qa-regression-reporting` | 품질 게이트·회귀 검증·보고서 |
